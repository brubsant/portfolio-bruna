Hackathon Infinity

Sobre o Projeto

Este projeto foi desenvolvido durante o Hackathon promovido pela Infinity School, com o objetivo de simular um ambiente de trabalho real e nos preparar para os desafios do mercado de Design e Tecnologia.

O desafio proposto foi a criação de uma solução interna para a própria escola: uma plataforma online para a exposição dos projetos dos alunos.
